DATASET DESCRIPTION (2-3 sentences)
--------------------------------------------------------------------------------

This project uses two primary data sources: (1) U.S. Census American Community 
Survey (ACS) 5-Year Data Profiles covering social, economic, housing, and 
demographic characteristics for all 3,143+ U.S. counties from 2009-2020, and 
(2) county-level presidential election results from 2000-2024. The ACS data 
comprises over 2,000 CSV files totaling 93 MB across four profile tables 
(DP02-DP05) with 500+ variables per county, while the presidential voting 
dataset contains 94,019 records spanning 7 election cycles.


BIG DATA JUSTIFICATION
--------------------------------------------------------------------------------

Volume:
- Total ACS data: 93 MB across 2,053 CSV files
  - Economic (DP03): 35 MB, 141 variables per county
  - Social (DP02): 31 MB, 158 variables per county  
  - Demographic (DP05): 14 MB, 85 variables per county
  - Housing (DP04): 13 MB, 145 variables per county
- Presidential voting data: 8.9 MB, 94,019 rows
- Combined: ~102 MB of structured data
- Coverage: 3,143+ counties × 12 years × 4 data profiles = ~150,000+ county-year records
- Hardware: macOS, Python 3.9.6, Pandas 2.3.3
- Execution time: Full download of all ACS tables takes ~45 minutes via Census API

Variety:
The two datasets have fundamentally different structures and purposes:

| Dataset              | Structure        | Content Focus                    |
|----------------------|------------------|----------------------------------|
| ACS Data Profiles    | Wide format      | 500+ socioeconomic variables     |
| (DP02, DP03, DP04,   | (many columns)   | per county: income, employment,  |
| DP05)                |                  | education, housing, demographics |
|----------------------|------------------|----------------------------------|
| Presidential Voting  | Long format      | Election results by candidate,   |
|                      | (many rows)      | party, and vote counts per       |
|                      |                  | county across 7 election cycles  |

These datasets complement each other: ACS provides the socioeconomic context 
(independent variables) while voting data provides political outcomes 
(dependent variables) for correlation analysis.


PROJECT OBJECTIVE (1 sentence + value explanation)
--------------------------------------------------------------------------------

Objective:
Analyze how county-level economic conditions correlate with voting patterns in 
U.S. presidential elections from 2000-2024.

Value:
Understanding the relationship between income inequality, employment rates, 
and voting behavior helps identify underserved communities and reveals 
socioeconomic-political dynamics at a granular geographic level. This analysis 
can inform policy decisions by highlighting which economic factors most 
strongly predict political preferences across diverse American counties.
